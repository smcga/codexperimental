# Demoscene AI Story Demo

Single-page demoscene-inspired web demo built with Vite + TypeScript, Canvas 2D, and Web Audio chiptune synthesis.

## Features
- Timeline-driven story text synced with music sections and visual effects.
- Classic demoscene visuals: starfield warp, plasma, tunnel, particles, scanlines, and glitch slices.
- Web Audio chiptune synth (lead, bass, arp, drums) with a clear drop section.
- Offline-friendly: no external assets.

## Controls
- Click **CLICK TO START** to begin (required for audio autoplay policies).
- Press **F** to toggle fullscreen.
- Press **R** to restart the demo.

## Development
```bash
npm install
npm run dev
```

## Tests
```bash
npm run test
```

## Production
```bash
npm run build
npm run preview
```
