# Demoscene AI Demo

Single-page demoscene-style demo built with Vite + TypeScript, HTML5 Canvas 2D, and Web Audio API.

## Features
- Timeline-driven story text synced to music
- Multiple classic demo effects (starfield, plasma, tunnel, particles, scanlines)
- Chiptune-style synth music with a beat drop
- Offline-capable, no external assets

## Commands
```bash
npm install
npm run dev
npm run test
npm run build
npm run preview
```

## Controls
- Click to start audio + visuals
- Press **F** to toggle fullscreen
- Press **R** to restart
