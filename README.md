# Demoscene Story Demo

A single-page demoscene-inspired web demo built with Vite + TypeScript, Canvas 2D, and the Web Audio API. The sequence is driven by a single timeline that syncs story text, classic demo effects, and a chiptune soundtrack with a clear beat drop.

## Requirements

- Node.js 18+
- npm

## Scripts

```bash
npm install
npm run dev
npm run test
npm run build
npm run preview
```

## Controls

- **Click** the overlay to start audio + visuals (required for autoplay policies).
- **F** to toggle fullscreen.
- **R** to restart the demo.
