# Public assets

- `song.mp3` must be placed in this folder. Replace the placeholder file with your own MP3 track.
- `timeline.json` controls the audio source, section timings, transitions, text cues, and layered effect mixes (supported transition types include `fade`, `wipe`, `slide-left`, `slide-right`, `slide-up`, `slide-down`, `iris`, and `flash`; layers support blend modes like `screen`, `overlay`, `multiply`, and `difference`). Use `gl_fractal_tunnel` to enable the WebGL2 shader effect with params like `quality`, `warp`, `hueShift`, `exposure`, and `seed`.
