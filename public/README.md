# Public assets

- `song.mp3` must be placed in this folder. Replace the placeholder file with your own MP3 track.
- `timeline.json` controls the audio source, section timings, transitions, text cues, layered effect mixes, and optional overlays (supported transition types include `fade`, `wipe`, `slide-left`, `slide-right`, `slide-up`, `slide-down`, `iris`, and `flash`; layers support blend modes like `screen`, `overlay`, `multiply`, and `difference`, and overlays include `blendIllusions` with modes `torch`, `glow`, `moire`, or `all`).
